# Google Search Console Setup

1. Deploy the site on Netlify.
2. Add your final domain in Google Search Console.
3. Verify ownership using the DNS method if possible.
4. Submit this sitemap:
   `https://your-domain.com/sitemap.xml`
5. Use URL Inspection for the homepage and request indexing.
6. Wait for impressions before making ranking conclusions.

## First queries to monitor

- roblox devex calculator
- roblox revenue calculator
- robux to usd devex calculator
- roblox gamepass calculator
- roblox developer earnings calculator

## What matters first

Impressions matter before clicks. If Google shows the site but nobody clicks, improve title and meta description.
If Google does not show the site at all, improve internal links, topical content, and indexing.
