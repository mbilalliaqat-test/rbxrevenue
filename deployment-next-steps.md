# Deployment Next Steps

1. Upload the full ZIP to Netlify.
2. Rename the deployed site to a clean brand name.
3. Add a custom domain if available.
4. Replace `https://your-domain.com` inside:
   - `sitemap.xml`
   - `robots.txt`
   - canonical links inside blog pages
5. Submit the sitemap in Google Search Console.
6. Wait for impressions before changing the design.
7. After 100+ impressions, improve title tags based on Search Console queries.

## Do not do this yet

- Do not add ads immediately.
- Do not add too many calculators.
- Do not redesign repeatedly.
- Do not stuff keywords unnaturally.
- Do not make unsupported payout promises.

## First KPI targets

- Google Search Console impressions
- Click-through rate
- Calculator interactions
- Copy result clicks
- Share link clicks
- Email signups, if added later
