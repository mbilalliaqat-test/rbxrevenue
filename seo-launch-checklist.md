# SEO Launch Checklist

## Before upload

- [ ] Rename the page title only if you have a stronger keyword target.
- [ ] Replace `your-domain.com` in `robots.txt` and `sitemap.xml`.
- [ ] Add Google Analytics or Plausible Analytics.
- [ ] Add Microsoft Clarity or Hotjar only after initial page speed check.
- [ ] Test the calculator on desktop and mobile.
- [ ] Check that all buttons work:
  - Robux to USD
  - Gamepass/Product
  - Break-Even ROI
  - Players Needed
  - Copy Result
  - Copy Share Link

## After upload

- [ ] Submit homepage in Google Search Console.
- [ ] Submit `sitemap.xml`.
- [ ] Add the site to Bing Webmaster Tools.
- [ ] Create 5 supporting articles internally linking to the calculator.
- [ ] Create 10 Reddit/Discord/creator-community posts carefully, without spam.
- [ ] Track rankings for:
  - Roblox DevEx Calculator
  - Roblox Revenue Calculator
  - Robux to USD DevEx Calculator
  - Roblox Gamepass Calculator
  - Roblox Creator Earnings Calculator

## Conversion improvements

- [ ] Add email capture: “Get Roblox Monetization Planner Template.”
- [ ] Add downloadable Google Sheet as lead magnet.
- [ ] Add affiliate section only after traffic starts.
- [ ] Add a “Save My Calculation” feature later if repeat users appear.

## Brutal warning

Do not overbuild before traffic. The calculator must prove demand first.
Traffic, repeat use, email signups, and ranking movement matter more than adding advanced features too early.
